UM LINK 웹사이트

구성
- index.html      : 서비스 소개 사이트 (화면 설계 갤러리 포함)
- app.html        : 작동형 시연 앱 (보호자 / 객실승무원 / 관리자)
- screens/        : 보호자 앱 8화면, 객실승무원 앱 4화면 이미지
- flight-journey.js   : 18초 비행 여정 애니메이션 엔진 (다른 페이지에도 삽입 가능)
- flight-journey.html : 애니메이션 단독 재생 페이지
- src/db/         : 저장·동기화 모듈 (기능별 분리)
- supabase/       : DB 스키마 및 권한 정책 SQL
- INTEGRATION.md  : Supabase 연결 가이드 (안 해도 앱은 동작함)


두 가지 모드
------------------------------------------------------------
[정적 모드] (기본값)
  설정 없이 바로 동작합니다. 데이터는 각 방문자의 브라우저에
  저장되고, 같은 브라우저의 탭 사이에서만 공유됩니다.
  인터넷이 없어도 동작합니다.

  => 한 대의 노트북으로 시연할 때 이걸로 충분합니다.
     "나란히 시연" 버튼으로 보호자/승무원 화면을 동시에 띄울 수 있습니다.

[실시간 모드] (선택)
  src/db/config.js 에 Supabase 주소와 anon 키를 넣으면 켜집니다.
  여러 기기가 같은 데이터를 봅니다. 승무원이 노트북에서 입력하면
  보호자 핸드폰 화면이 즉시 바뀝니다.

  => 심사위원에게 핸드폰을 건네 직접 보게 할 때 필요합니다.
     설정 방법은 INTEGRATION.md 참고.

  연결에 실패하면 자동으로 정적 모드로 떨어집니다.
  즉 발표장 인터넷이 막혀도 시연 자체는 됩니다.


배포 방법 (택 1, 모두 무료)
------------------------------------------------------------
1. Netlify Drop: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓기
2. GitHub Pages: 저장소에 파일을 올리고 Settings > Pages에서 배포
3. 내 컴퓨터: index.html을 브라우저로 열기


개인정보 주의
------------------------------------------------------------
- 모든 데이터는 가상 데이터입니다.
- 실제 아동의 이름·나이·사진·보호자 연락처를 넣지 마세요.
  실시간 모드의 anon 키는 공개되는 키라서, 키를 아는 사람은
  데이터를 읽을 수 있습니다. (자세한 내용: supabase/02_rls_demo.sql)
- 사진은 AI 생성 이미지 또는 팀원 본인 사진만 사용하세요.
- Supabase service_role 키는 어떤 파일에도 넣지 마세요.
- 결제는 테스트 결제만 있고 실제 청구는 없습니다.


참고 · 비행 여정 항공기 이동 지도
------------------------------------------------------------
- 보호자 앱 > 비행 여정 화면에 인천(ICN) → 로스앤젤레스(LAX)
  항공기 이동 지도가 있습니다.
- 일반 웹 호스팅에서는 Leaflet + OpenStreetMap 실제 지도로 표시됩니다.
- 지도 라이브러리나 타일을 불러오지 못하면 경위도 격자만 그린
  '시뮬레이션 지도'로 자동 전환됩니다.
- 재생 / 일시정지 / 처음으로 / 진행률 슬라이더 / 재생 속도를 지원합니다.
- 항공기 위치·고도·속도는 시연용 예시 값이며, 실제 항공편 API는
  연결되어 있지 않습니다.

  계산하지 않고 화면 값을 그대로 씁니다.
- 데이터 위치: app.html 안의 FLIGHT_KE017 상수 (검색: FLIGHT_KE017)

[변경 내역] Flight Journey 18초 애니메이션 (ICN → LAX)
- HTML·CSS·JavaScript(Canvas)로 만든 영상형 애니메이션입니다. 1920×1080, 16:9.
- 장면: 0–3초 출발지 / 3–6초 출발 / 6–12초 태평양 횡단 / 12–15초 LA 접근 /
  15–18초 도착
- 보이는 곳: flight-journey.html(단독), 소개 사이트 '여정 영상' 섹션,
  앱 > 보호자 > 비행 여정 > '▶ 여정 영상' 버튼
- 해안선은 ECharts world 지도 데이터를 인터넷에서 불러옵니다. 연결이 없으면
  경위도 격자 화면으로 재생됩니다.

[변경 내역] 인수 코드 (최종 인계 확인)
- 보호자가 1회용 6자리 코드를 발급해 인수자(마중 나온 가족)에게 전달합니다.
- 도착지에서 인수자가 코드를 지상직원에게 보여주면, 지상직원이 신분증과 함께
  확인하고 아이를 인계합니다.
- 이 시스템을 쓰는 사람은 보호자와 항공사 직원뿐입니다. 마중 나온 가족은
  사용자가 아니라 코드를 제시하는 쪽입니다.
- 지상직원 앱에는 '인수자 확인' 화면 하나뿐입니다. 체크인 등록·탑승 인계는
  넣지 않았습니다 (기존 절차 그대로).
- 시연 계정: ground01 (지상직원 · Jordan Lee · LAX 도착 서비스)

[변경 내역] 알림 클릭 이동
