구성
- index.html      : 서비스 소개 사이트 (화면 설계 갤러리 포함)
- app.html        : 작동형 시연 앱 (보호자 / 객실승무원 / 관리자)
- screens/        : 보호자 앱 8화면, 객실승무원 앱 4화면 이미지
- flight-journey.js   : 18초 비행 여정 애니메이션 엔진 (다른 페이지에도 삽입 가능)
- flight-journey.html : 애니메이션 단독 재생 페이지
- src/db/         : 저장·동기화 모듈 (기능별 분리)
- supabase/       : DB 스키마 및 권한 정책 SQL
- INTEGRATION.md  : Supabase 연결 가이드 (안 해도 앱은 동작함)

참고 · 비행 여정 항공기 이동 지도
------------------------------------------------------------
- 보호자 앱 > 비행 여정 화면에 인천(ICN) → 로스앤젤레스(LAX)
  항공기 이동 지도가 있습니다.
- 일반 웹 호스팅에서는 Leaflet + OpenStreetMap 실제 지도로 표시됩니다.
- 지도 라이브러리나 타일을 불러오지 못하면 경위도 격자만 그린
  '시뮬레이션 지도'로 자동 전환됩니다.
- 재생 / 일시정지 / 처음으로 / 진행률 슬라이더 / 재생 속도를 지원합니다.
- 항공기 위치·고도·속도는 시연용 예시 값이며, 실제 항공편 API는
  연결되어 있지 않습니다.

[참고] 미러링 테이블의 운항 단계
- 앱은 scheduled / boarding / departed / cruise / descent / landed 6단계를 씁니다.
- DB flights.phase 제약조건은 scheduled / checkin / boarding / enroute /
  landed / handed_over 라서, 비행 중 세 단계는 enroute 하나로 들어갑니다.
- 세밀한 단계는 demo_state 의 JSON 원본에 그대로 남아 있습니다.

[변경 내역] 주소 정리
- _redirects 파일을 추가해 .html 없는 주소를 씁니다.
    /app      -> 작동형 앱      (기존 /app.html 도 그대로 열립니다)
    /demo     -> 작동형 앱      (같은 화면, 외우기 쉬운 주소)
    /journey  -> 여정 영상 단독 재생
    /         -> 소개 사이트
- /app.html 을 /app 으로 돌려보내는 301 은 일부러 넣지 않았습니다.
  되돌림 루프가 나면 두 주소가 동시에 죽기 때문에, 예전 주소도 살려 둡니다.
- manifest 의 start_url 을 /app 으로 바꿨습니다. 홈 화면에 설치하면
  주소창 없이 /app 으로 열립니다.
- 이 파일은 Netlify 전용입니다. GitHub Pages 에서는 무시되고,
  그때는 /app.html 주소를 쓰면 됩니다.
